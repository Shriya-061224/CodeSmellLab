
# CodeSmellLab 🧪

**CodeSmellLab is an interactive playground for learning code quality — not just writing code that happens to work.**

Most tutorials show you the *perfect* solution right away.
Real codebases aren’t like that.

CodeSmellLab flips the script.

Instead of starting with ideal implementations, you begin with **naive, messy, or inefficient code**. You learn *why* it smells, what problems it causes, and then you refactor it using better patterns and ideas.

Because the fastest way to write clean code…
is to first recognize bad code when you see it.

---

## What you’ll do in CodeSmellLab

* Explore intentionally flawed implementations
* Understand **why** certain approaches hurt performance or design
* Refactor code step by step
* Get feedback on your improvements — not just pass/fail results

This isn’t about memorizing patterns.
It’s about learning how to *think* about code quality in the real world.

* TypeScript
* Python
* Java
* C++
* Go

### Topics

* Core data structures:

  * Stack
  * Queue
  * Linked List
  * Hash Map
  * Heap

### Learning focus

* Time complexity (what actually gets slower and why)
* Memory behavior
* Design trade-offs
* Hands-on refactoring with guided validation and detailed feedback

## Run and deploy the app

### Run locally

**Prerequisites:** Node.js

1. Install dependencies:

   ```bash
   npm install
   ```
2. Set your `GEMINI_API_KEY` in `.env.local`
3. Start the dev server:

   ```bash
   npm run dev
   ```
